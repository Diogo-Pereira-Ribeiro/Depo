# Depo - Extensões de Anime para Aniyomi

Repositório com extensões de anime para o **Aniyomi**.

## 📥 Como Adicionar ao Aniyomi

1. Abra o Aniyomi
2. Vá para **Definições > Navegador > Repositórios de Extensões**
3. Clique em **Adicionar** para adicionar um novo repositório
4. Cole a URL abaixo:

```
https://raw.githubusercontent.com/Diogo-Pereira-Ribeiro/Depo/repo-public/index.min.json
```
